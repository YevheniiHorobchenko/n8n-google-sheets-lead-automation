n8n Google Sheets Lead Automation

Overview

A simple workflow that receives lead data, prepares the information, and saves it to Google Sheets.

Workflow

1. Manual Trigger – starts the workflow.
2. Edit Fields – prepares lead information.
3. Google Sheets – appends a new row to the spreadsheet.

Tools & Technologies

- n8n
- Google Sheets
- Google OAuth2

What I Learned

- Building workflows in n8n
- Connecting Google Sheets using OAuth2
- Mapping data between nodes
- Appending data to Google Sheets

Project Status

Completed as a learning project.
